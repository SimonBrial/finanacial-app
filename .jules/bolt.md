## 2024-05-18 - Avoid StyleSheet.flatten in render functions
**Learning:** Using `StyleSheet.flatten` inside render functions (especially in frequently used core UI components like Stack, Row, Typography, Container) causes a measurable CPU performance overhead. `StyleSheet.flatten` recursively merges style objects, creating new object allocations on every render. Since React Native natively supports array styles (`style={[style1, style2]}`) and resolves them efficiently on the native side, flattening is an unnecessary anti-pattern for regular rendering.
**Action:** Always pass arrays of style objects directly to the `style` prop instead of manually flattening them, unless you strictly need to extract a specific property value (like a color or height) in JavaScript before rendering.
